# Knowledge index

Method knowledge for the stage skills. Read the file a skill points to; do not load everything.

| File | Read when |
|---|---|
| `knowledge/claims.md` | before the first `claim add`; whenever unsure of a claim's type or kind |
| `knowledge/case-types.md` | intake: classifying the case; plan: picking criteria |
| `knowledge/objections.md` | options: writing and judging objections |
| `knowledge/product-strategy.md` | strategy: the product part |
| `knowledge/comms-strategy.md` | strategy: the communication part and the promise check |
| `knowledge/verification-plan.md` | strategy: the verification plan |
| `knowledge/templates/` | writing any case document: copy the template, keep every `##` heading |

Search this folder with `rg -n "<term>" knowledge/` (or plain grep when ripgrep is missing).
