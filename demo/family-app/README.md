# Демо-кейс: «Семейный компас»

**Все данные вымышлены.** «Семейный компас» - придуманное приложение семейной геолокации и
безопасности по подписке; его продают в приложении и как опцию у оператора-партнёра (оператор
не назван и не существует). Метрики, тарифы, рекламные тексты и обращения в поддержку сгенерированы
скриптом `make_materials.py` для демонстрации и не являются данными какой-либо компании.
Конкурентов агент ищет сам по открытым страницам: они настоящие.

## Что в папке

- `request.md` - первое сообщение руководителя продукта агенту.
- `materials/metrics.xlsx` - лист `monthly` (12 месяцев, ноябрь 2025 - октябрь 2026: платящие
  семьи, новые, ушедшие, отток %, MRR, версия онбординга, удержание новых через месяц), лист
  `cohorts` (когорты по месяцу первой оплаты и каналу привлечения: удержание через 1, 2 и
  3 месяца), лист `about` (определения столбцов и пометка о вымышленных данных).
- `materials/product.docx` - описание продукта: что делает, тарифы, каналы, новый онбординг,
  рекламный текст нового платного канала.
- `materials/support-tickets.csv` - 32 темы обращений в поддержку по месяцам и каналам, без
  персональных данных.
- `make_materials.py` - генератор материалов. Детерминированный: повторный запуск даёт те же
  таблицы и тексты.

Пересоздать материалы:

```bash
.venv/bin/python demo/family-app/make_materials.py
```

## Как запустить

1. Установите и проверьте проект по корневому `README.md` (`bin/strat state`).
2. Запустите Claude Code в корне репозитория и отправьте текст из `request.md` как первое
   сообщение.
3. Агент сам создаст кейс в `cases/`, зарегистрирует материалы через `bin/strat source add` и
   остановится на трёх воротах.

Помесячная таблица подсказывает простой ответ: новый онбординг (v2) вышел 30 апреля, его видят
все новые пользователи с мая, и именно с майских новичков удержание через месяц упало с ~91,5%
до ~73%, а общий отток вырос с ~4% до ~7,7% с июня.

Таблица когорт по каналам показывает другое. В мае же запущен новый платный канал
`performance_ads` с рекламой «узнайте, где ребёнок, просто по номеру, ничего не устанавливая на
его телефон». Продукт этого не делает: нужно приложение-компаньон на телефоне ребёнка, а по
номеру работает только у оператора-партнёра и грубо. Из этого канала через месяц уходит ~48%
семей, через два - ~66%. Отток в первый месяц у остальных каналов после мая почти тот же, что
до: около 10-11% у органики, 8% у рефералов, 6% у абонентов оператора. Темы обращений в
поддержку с мая - в основном про обещание из рекламы.

Значит, ведущий вариант должен сместиться с «вернуть старый онбординг» на «поменять, кому и что
мы обещаем в платном канале» (текст рекламы, таргетинг, честное объяснение установки до оплаты).

Место для честного сомнения, чтобы агент рассуждал, а не списывал ответ:

- у органики отток в первый месяц после мая вырос примерно на 1 п.п. (около 10% до мая и
  около 11% после), и в поддержке есть органические обращения «не понял после оплаты, что нужно
  ставить второе приложение»: v2 перенёс этот экран после оплаты, так что небольшой вклад
  онбординга возможен и, вероятно, усиливает проблему платного канала;
- у когорты `operator_bundle` за июнь 2026 нет данных об удержании: выгрузка оператора не
  получена;
- по когортам августа - октября данных о M2 и M3 ещё нет.

Тест `tests/test_demo_case.py` следит, чтобы цифры не потеряли этот поворот.
