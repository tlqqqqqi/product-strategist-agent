Ключевые цифры

Почему

  • Отток вырос с 4% (апрель) до 7,6% (октябрь) при том, что онбординг v2 почти не изменил удержание нерекламных каналов (−0,32…−1,03 п.п.) — падение сосредоточено в performance_ads C049 C079 C080 C087вывод.
  • Реклама обещает «ничего не нужно устанавливать», но без приложения-компаньона продукт даёт только грубую локацию по сети оператора-партнёра после SMS-согласия; 82,35% обращений канала — про этот разрыв C059 C083 C076.
  • Канал при CAC ~650 ₽ едва окупается (LTV ~620–628 ₽), а его M1 ~52% хуже рыночной нормы (отток 15–40% на первом продлении) C060 C032прогноз C086 C090вывод.

Какие варианты рассматривали

  • Откат v2 — отклонён: удержание других каналов после v2 не упало, причина не в онбординге C079 C080 C087вывод.
  • Закрыть канал — запасной вариант: снимает источник плохого M1, но бьёт по половине притока новых семей C072 C089вывод.
  • Только честная реклама или только экран — слабее гибрида, эффекты складываются C088вывод C091пробел.

Продукт

  • Направление: честные креативы (установка компаньона, согласие ребёнка, точность по сети), понятный экран после оплаты, пилот с порогами C059 C083 C091пробел C094прогноз.
  • Отказы: не откатывать v2, не обещать «без установки», не закрывать канал до пилота C079 C080 C059 C083 C072.

Коммуникация

  • Ключевое сообщение: «Чтобы видеть ребёнка точно, на его телефон ставится приложение — он видит, что локация включена; без него — приблизительная локация по сети оператора-партнёра с согласием» C084 C083.
  • Доказательство: возможности продукта и честный экран вместо разрывного обещания C084 C083 C076.
